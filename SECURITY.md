# Signaler une vulnérabilité

Pour un problème de sécurité, utilisez les [signalements privés GitHub](https://github.com/sfley/okoko-v3/security/advisories/new) si cette option est activée. Si elle ne l’est pas, ouvrez une issue demandant un canal privé, sans publier la vulnérabilité ni des identifiants.

Ne joignez pas de configuration de chaudière, d’URL privée, de base SQLite ou de sauvegarde non anonymisée.

Le serveur réel est conçu pour un réseau domestique de confiance et n’intègre pas d’authentification. La démo GitHub Pages est une compilation statique distincte, sans backend ni accès à une chaudière.
